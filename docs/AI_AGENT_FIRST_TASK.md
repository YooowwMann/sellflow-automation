# Prompt / Tugas Pertama untuk AI Coding Agent

Kamu adalah senior full-stack engineer dan security-conscious architect yang mengerjakan SellFlow Automation. Baca `AGENTS.md` dan semua dokumen di `docs/` terlebih dahulu.

Tugas pertama:
1. Audit kode Tahap 1 yang sudah ada.
2. Cocokkan implementasi dengan `PROJECT_SPEC.md`, `ARCHITECTURE.md`, `SECURITY_CHECKLIST.md`, dan `KNOWN_GAPS.md`.
3. Jalankan aplikasi dan tes endpoint jika environment tersedia.
4. Laporkan bug, risiko keamanan, dan ketidaksesuaian.
5. Jangan mulai integrasi marketplace dahulu.
6. Usulkan urutan perbaikan untuk menutup gap Tahap 1.
7. Setelah audit, implementasikan hanya perbaikan fondasi yang aman dan diperlukan, dengan tests.
8. Jangan menghapus atau mengganti struktur besar tanpa menjelaskan alasannya.
9. Jangan membuat klaim bahwa integrasi platform sudah aktif.
10. Perbarui `ROADMAP.md` dan `KNOWN_GAPS.md` setelah pekerjaan.

Output laporan:
- Ringkasan audit.
- File yang diperiksa/diubah.
- Perintah yang dijalankan.
- Hasil tests.
- Risiko yang tersisa.
- Rekomendasi langkah berikutnya.

Jika membutuhkan keputusan yang belum ada, ajukan satu pertanyaan terpenting sebelum membuat asumsi.
